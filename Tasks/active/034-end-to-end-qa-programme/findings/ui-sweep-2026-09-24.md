# UI sweep — layout, theme and state defects (task 034)

Finding prefix `UIX`. Headless sweep on 2026-09-23/24 against a throwaway server started with the
e2e harness (`e2e/support/harness.js`, own Mongo on 27159, the standard fixture workspace: owner,
admin, member, guest, two projects, three tasks), signed in as the owner. Chrome (system install)
driven by `playwright-core`, one browser at a time. The tours, the getting-started card and the
notification prompt were suppressed so they did not cover the screens.

15 screens × 390 / 800 / 1280 px × light / dark = 90 captures: Home, project List / Board / Calendar,
task detail, Inbox, Approvals, AI → Agents, AI → Skill library, AI Inbox, Settings → Members,
Settings → Instance → Health / Egress / Knowledge, Timesheet. Each capture was audited in the page
for: horizontal page scroll, elements past the right edge, clipped nowrap text, overlapping controls,
text contrast below 4.5:1 (3:1 for large text; colours blended over the real background stack),
raw i18n keys, broken images, controls under 32 px at 390 px. Screenshots are not committed.

Clean across all 90 captures: no horizontal page scroll, no raw i18n keys (the Skill library shows
tool ids such as `task.comment` on purpose), no broken images.

## Before / after

The sweep was re-run after the fixes on a rebuilt bundle (same fixture, same widths and themes).

- UIX-01: tab bar 86 px → 56 px, labels visible on every 390 px capture; Home sidebar groups
  compact, project names untruncated; "Assigned to me" in the brand colour; no nav padding left.
  Docs, Dashboards, Personal list and Inbox (not in the matrix) were checked at 1280 as well.
- UIX-02/03: calendar grid 0 px → 326 px wide at 390; bar back on top at 1280 (grid 1146 px).
  Left over: on a phone the seven day columns are ~89 px each, so the month scrolls sideways
  inside the grid (Mon and Tue visible first).
- UIX-04: every failure inside the dark task panel's content is gone (Checklist, created-by,
  "+ New page", teaser title, description box). What the audit still lists at 1280 dark is
  `--ink-3` text (UIX-10) in the breadcrumb and the list behind the panel, and a legacy grey
  watcher count (2.98:1).
- UIX-05: banner right edge 977 → 951 px, flush with the column.
- UIX-06: frame, chevron discs and the month-title failure gone in dark.
- UIX-07: filter pill ~42 px wide, no longer under the search toggle.
- UIX-09: "Show figures" inside the card (right edge 319 of 358).

Each fix has a regression check in `frontend/tests/unit/uiSweepStyles.spec.js` (the rules are
stylesheet-level, so the spec reads the stylesheets rather than mounting components).

## How to re-run

Scripts lived in the session scratchpad and are not committed; the recipe: start the harness with
`startHarness` against your own `E2E_MONGODB_URL`, save the owner's storage state through
`signInThroughForm`, then for each theme set `localStorage['ah.theme']`, mark
`ah.tour.skipped.{shell,project,board,list}` and `sessionStorage['ah.gs.dismissed']`, grant the
`notifications` permission, and visit each route at each width.
