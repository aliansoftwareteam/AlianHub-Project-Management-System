# Ten things to say

Say these to Claude or ChatGPT, in your own words. Change the names to yours.

If you say "here" or "this list", your AI can look up the project, list or task you last had open. Open the screen you mean first.

What happens below is what AlianHub does when the project uses the default rule, "Act on single tasks, propose anything wider". The ones marked "Needs" need a permission you ticked when you connected. See [Connect your AI app](./connect).

| # | Say this | What happens |
|---|---|---|
| 1 | Move "Design" to In progress. | Done at once. You can undo it. It can set In progress or In review, and no other status, unless you gave it Manage tasks. |
| 2 | Add a task "Call supplier" to the Launch list. | Done at once. You can undo it. The task gets the project's first status and nobody is assigned. |
| 3 | Comment on "Design": the logo is ready. | Done at once. You can undo it. |
| 4 | Log 1 hour 30 minutes on "Design". | Done at once. You can undo it. It logs your own time, for today. A day in an approved timesheet period is refused. |
| 5 | Find the tasks about the supplier. | Nothing changes. You get the tasks you can open that match. |
| 6 | Set "Design" to high priority and assign it to Priya. | Needs Manage tasks. Done at once, one task, and you can undo it. Without Manage tasks it cannot do this. |
| 7 | Mark "Design" as Done. | Needs Manage tasks. By default it waits in the AI Inbox until you approve. If the project says "Never", or your workspace has a person check before a task is closed, it is refused and a person closes the task. |
| 8 | Add a board view called "Board" to this project, grouped by status. | Waits in the AI Inbox. Everyone on the project would see it, so you approve it first. |
| 9 | When a task's status changes, add a comment "Status changed". | Only an owner or admin can ask for this. It waits for an owner or admin to approve. The rule is saved switched off, unless you ask for it to be on. |
| 10 | Delete the task "Old plan". | Nothing happens. Your AI has no way to delete a task, a project, a doc or a comment. Delete it yourself. |

## More to try

| Say this | What happens |
|---|---|
| Open the task about the supplier, and open the doc about the launch. | Nothing changes. You get two links. |
| Show me each person's workload in this project for this week. | Nothing changes. You get a link to the Workload view, which opens on this week. |
| Show me all my tasks across every project. | Nothing changes. You get a link to the Everything screen, opened on your own tasks, or the list in the chat. |
| Set these twenty tasks to high priority and assign them all to Priya. | Needs Manage tasks. Waits for approval, as one request, because it names many tasks. |
| Show my tasks due this week and save it as a view called "Mine this week". | Waits for approval. |
| Create a doc "Launch notes" with the line "First draft". | Needs Write docs. The doc is made at once, with Undo, and marked as the AI's draft. |
| Make a task in the Launch list from the last message in this channel. | Needs Read chat and Manage tasks. Done at once, with Undo. |

## Ready-made asks

Your AI app can also offer these by name: Set up my project, Plan my day, What is at risk, Write the status report and Triage what is new. All of them show you a result first. They change something only after you say yes.
