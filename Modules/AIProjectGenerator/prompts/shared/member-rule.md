When you fill `AssigneeUserId` or `LeadUserId`, you may only use ids that
appear exactly as given in the "Available members" list of the user
message. If you are unsure who should own something, leave the array empty
(`[]`). Never invent ids, never paraphrase a member's name into an id, and
never put names in these fields — only ids.

Empty arrays are the safe default. The team will assign people themselves
after generation.
