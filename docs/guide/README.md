## Go deeper

- [Views, filters and saved views](views.md): List, Board, Table, Calendar, Gantt and Workload. Filter, group, sort and totals. Saved views.

- [Rules (automations)](rules.md): triggers, conditions, actions, the preview, who a rule runs as, and what a rule cannot do.
