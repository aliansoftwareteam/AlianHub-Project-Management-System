# 3. Lists, folders and tasks

- A **project** holds lists.
- A **list** holds tasks.
- A **task** can hold subtasks, up to three levels.
- A **folder** is optional. It groups lists. A folder can hold one level of subfolders.

A task always lives in a list. A new project already has one list called "List".

## Add a task

Pick one way:

- In the project, select **Create task** on the empty screen.
- Select **+ New**, then **Task**. Type a name of at least 3 characters. You can also set Status, Assignee and Due date here. Select **Create task**.
- In the List view, select **+ Add task to** a group at the bottom of the group.
- Press **C** anywhere.

If AlianHub says "Choose a list first", add a list (below).

## Add a list or a folder

Select **+ New**, then **New list** or **New folder**. Type a name and save. A list started from inside a folder is made in that folder.

## Open a task

Select a task. A panel opens on the right. It has:

- **Details**: Status, Assignee, Due Date and more.
- Tabs for **Description**, **Subtasks**, **Files** and **Relations**.
- **Activity**, with **Comments** and **History**.

## Change a status

Select the status dot in a List row, or the **Status** field in the panel. Pick a new one. You can also drag a card on the Board (see [The views](04-views.md)). **Complete** marks the task done.

## Add a subtask

In a task, open the **Subtasks** tab and select **+ Add Subtask**. In the List view, the **...** menu on a row has **Add subtask**.
