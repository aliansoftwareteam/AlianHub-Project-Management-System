# 7. Time

You can log the time you spend on a task and see it on a weekly timesheet.

## Turn it on for a project

The **Time** part of a task appears only when the project's **Time Tracking** app is on. It is chosen under **Apps** when you make a project, or in **Settings**, then **Projects**, then **Apps**.

## Log time on a task

Open the task and find **Time**.

- **Start timer** starts a clock. **Stop and log time** saves it. You must be an assignee of the task, and the task must not be done.
- **Add time** lets you type it in: Date, Start, Hours, Minutes, a Note, and **Billable**. Select **Save time**.

## Log time from the Log time page

Open **Time** in the left bar, then **Mine**. Select **Log time**. Pick a **Task**, type **Hours**, choose **When**, and select **Log**. Entries stay editable until the week is submitted.

## The timesheet

**Time**, then **Mine** is **My timesheet**. It shows one week, with a row for each task and a column for each day.

- Arrows move between weeks.
- **Submit week** sends the week to be approved. The week then shows as Submitted, then Approved or Rejected.
- If it is rejected, change it and select **Resubmit week**.
- Owners and admins review under **Approvals**.

Other tabs, if your role allows them: **Project**, **Workload** and **Tracker**.
