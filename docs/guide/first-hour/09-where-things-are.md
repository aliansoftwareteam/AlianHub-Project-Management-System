# 9. Where things are

The bar down the left edge holds your places. On a phone it is a bar at the bottom, with **More**. Some places sit under **More** in the full bar too.

| I want to ... | Go to |
|---|---|
| Add a task from anywhere | **New task** at the top of the left bar, or press **C** |
| Go to the start page | **Home** |
| See all work, or only mine | **Everything** (shown as **My work** in the simple bar) |
| Open or start a project | **Projects** |
| See what needs me | **Inbox** |
| Open the planner | **Planner** |
| Talk to my team | **Chat** |
| Ask the built-in AI | **AI**, then **Ask** |
| Connect my AI app | **AI**, then **Connect your AI** |
| Write a document | **Docs** |
| Log or check time | **Time** |
| Search for anything | Press Ctrl and K (Cmd and K on a Mac) |
| Invite someone | **More**, **Members**, or **Settings**, then **Members** |
| Change my notifications | **Settings**, then **Notifications** |
| Change my profile | Your picture at the bottom of the left bar, then **My profile** |
| Log out or switch workspace | Your picture at the bottom of the left bar |
| See reports | **More**, then **Reports** |
| Approve timesheets | **More**, then **Approvals** (owners and admins) |
| Find something I deleted | **More**, then **Trash** |
| Change workspace settings | **More**, then **Settings** |
| Learn the keys | Your picture, then **Keyboard shortcuts** |
