# Hosting AlianHub (AlianHub Cloud)

AlianHub Cloud runs the same AlianHub as everyone else, switched to `HOSTING_MODE=managed`. There
is no separate hosted fork: every change the hosted product needs, including code that only runs
in managed mode, ships in this public repository under the same AGPL-3.0 licence and goes through
the same pull requests, tests and releases.

- [env-matrix.md](env-matrix.md) says who sets each environment variable on a hosted instance:
  the stack's `.env`, the platform, the customer's owner, or nobody (the default is right).
  It is generated by `node scripts/env-doc.js`.
- The login page and the profile menu link **Source code** to the exact build that is running:
  the release tag for a release, the commit for a build between releases (AGPL §13).
- Without `HOSTING_MODE`, or with `HOSTING_MODE=self`, nothing here applies and a self-hosted
  instance behaves as it always has.
